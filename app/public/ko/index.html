당신의 웹사이트를 AI로.
무료로.

링크를 붙여넣으세요. 당신 또는 당신의 비즈니스를 아는 맞춤형 AI를 약 2분 만에. 신용카드 불필요.

모든 공개 웹사이트에서 작동합니다. 공개 전에 모든 것을 직접 승인합니다.

작동 방식

  1. 1

    링크 붙여넣기

    설정은 그게 전부입니다. 업로드도, 설정도, 코드도 필요 없습니다.

  2. 2

    사이트를 읽습니다

    페이지, PDF, 심지어 동영상까지 — AI가 당신의 비즈니스가 실제로 말하는 것을 학습합니다.

  3. 3

    AI와 대화하기

    실시간으로 만들어지는 과정을 보고 바로 사용해 보세요. 공유하거나, 웹사이트에 넣거나, 비공개로 유지하세요.

제공되는 것

당신의 콘텐츠로 답변

AI는 웹사이트에 있는 내용으로 답하고 출처를 보여줍니다. 그래서 고객이 신뢰할 수 있습니다.

손님 맞을 준비 완료

당신의 콘텐츠로 작성된 환영 메시지와 추천 질문.

당신다운 모습

로고와 이름이 자동으로 적용됩니다. 붙여놓은 봇이 아니라 비즈니스의 일부처럼 느껴집니다.

코드 한 줄로 웹사이트에

코드 한 줄로 기존 사이트에 채팅을 추가하세요 — 또는 링크만 공유해도 됩니다.

원한다면 전화번호도

AI에 전화번호를 부여하면 비즈니스를 대신해 전화와 문자에 응답합니다.

고객에게 발견되기

원하면 공개 디렉터리에 AI를 등록해 새로운 고객이 찾아오게 하세요.

신뢰받는 이유

  • 출처를 밝힙니다. 모든 답변은 출처 페이지로 연결됩니다.
  • 통제권은 당신에게. 허락하기 전에는 아무것도 공개되지 않으며 언제든 삭제할 수 있습니다.
  • 무료로 시작. 신용카드 불필요. 성장하면 간단한 정액 요금제.

자주 묻는 질문

정말 무료인가요?

네 — AI를 만들고 사용해 보는 것은 무료이며 신용카드도 필요 없습니다. 무료 한도를 넘어서면(많은 방문자가 채팅하면) 간단한 정액 요금제가 있습니다.

내 비즈니스에 대해 지어내지 않나요?

웹사이트의 실제 콘텐츠로 답변하고 사용한 출처 페이지를 보여줍니다. 사이트에 없는 내용이라면 추측하지 않고 그렇다고 말합니다.

코딩을 알아야 하나요?

아니요. 링크만 붙여넣으면 AI가 스스로 만들어집니다. 나중에 웹사이트에 넣는 것도 코드 한 줄이면 되고, 정확한 위치도 알려드립니다 — 또는 AI 링크를 공유하기만 하세요.

웹사이트가 바뀌면요?

언제든 다시 스캔해 AI를 최신 콘텐츠로 유지할 수 있습니다.

고객의 개인정보는 어떻게 되나요?

대화는 당신의 비즈니스 내에서만 비공개로 유지됩니다. 데이터를 판매하지 않으며, AI와 데이터는 언제든 삭제할 수 있습니다. 개인정보 처리방침.

어려운 일은 당신의 웹사이트가 이미 해냈습니다.

24시간 당신을 위해 일하는 AI로 바꾸세요.
