Add it to your assistant

Claude

Web, desktop or mobile · works on the free plan

  1. Open Settings → Connectors, then Customize → Connectors.
  2. Click Add, then Custom. If it asks for a type, choose Web.
  3. Paste https://mcp.divinci.app/mcp as the remote MCP server URL and click Continue.
  4. Click Connect and sign in. That step creates your Divinci account if you don't have one.

On Team and Enterprise plans an owner adds the connector once under Organization settings, and everyone else then clicks Connect.

ChatGPT

Plus or Pro · custom MCP servers live behind Developer Mode

  1. In ChatGPT on the web, open Settings → Apps → Advanced and turn on Developer Mode.
  2. Add a connector and paste https://mcp.divinci.app/mcp as the MCP server URL.
  3. Sign in when prompted — that creates your Divinci account if you don't have one.
  4. In a chat, use + → More → Developer Mode → Add sources and switch Divinci on.

On Business, Enterprise and Edu, a workspace admin can turn Developer Mode off or allowlist specific connectors — so this may need them.

Grok

Paid tiers · web, iOS and Android

  1. Go to grok.com/connectors.
  2. Choose New Connector, then Custom.
  3. Paste https://mcp.divinci.app/mcp and save.
  4. Sign in when prompted — that creates your Divinci account if you don't have one.

xAI calls this "Bring Your Own MCP".

Claude Code

One command · this is the genuinely one-step path

  1. Run claude mcp add --transport http divinci https://mcp.divinci.app/mcp
  2. Run /mcp inside Claude Code and choose divinci to sign in.

The same command works in any MCP client that takes a remote HTTP server — Cursor, Windsurf, Zed and others.
