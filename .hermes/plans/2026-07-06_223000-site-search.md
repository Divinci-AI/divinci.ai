# Site-Wide Search (Blog + Whole Site) Implementation Plan

> **For Hermes:** Use the Omnigent `divinci-team` bundle to implement this plan task-by-task. Handoff brief: `docs/tickets/2026-07-06-site-search.md`.

**Goal:** Add instant, fuzzy, client-side search across the entire divinci.ai site (marketing pages + blog) reachable from the global header search box and the blog page, with a Cmd/Ctrl+K command-palette modal.

**Architecture:** A Python build script generates a small per-language JSON index (`search-index.<lang>.json`) from `site/content/` *before* `zola build` (so Zola copies it into `public/`). A vendored Fuse.js (no external CDN for core site) plus a small `search.js` load the index for the active language, run fuzzy matching, and render results in a keyboard-accessible modal. Header gets a search trigger; blog page gets an inline filter input that reuses the same engine.

**Tech Stack:** Zola (static site), Python 3 (index builder), Fuse.js v7 (vendored), vanilla JS + CSS, Cloudflare Worker static hosting. No backend, no external network calls at runtime.

## Context / Assumptions

- Repo: `/Users/mikeumus/Documents/divinci.ai`, site root `site/`. Build = `zola build`; deploy = `wrangler deploy` (staging `--env staging`, prod `--env=""`).
- 12 languages configured; blog content is EN-only (other langs link to 404s if searched). Marketing/legal pages have translations under `content/<lang>/`.
- Existing pattern: `cli.html` already does client-side `<input type=search>` filtering — reuse the same UX conventions.
- Design system: DM Sans (UI) + Fraunces (headings). Search UI must match (no new fonts).
- `site/public/` is gitignored; `site/static/` is committed. Index lives in `static/` so it ships to `public/`.

## Scope (v1)

- Index = all blog posts + all top-level marketing pages (everything under `content/blog/` and `content/*.md` except `sitemap.md`).
- Per-language indexes: `search-index.<lang>.json` for each language that has content; EN is the default. Search UI loads `search-index.{current_lang}.json`, falls back to `search-index.en.json`.
- Excluded from index: `sitemap.md`, any page with `extra.hidden = true`, and section `_index.md` stubs.
- Blog page: an inline search box at the top of the post list that filters the grid live (same Fuse instance / index).

## Open questions (team may decide, defaults noted)

- Include legal pages (terms/privacy) in search? **Default: yes, they have summaries**; low cost.
- Ranking weight: title (0.4) > tags/categories (0.3) > excerpt (0.2) > url (0.1). Tunable in `search.js`.

## Task 2: Write the search-index builder

**Objective:** Generate `site/static/search-index.<lang>.json` for each language at build time.

**Files:**
- Create: `site/scripts/build-search-index.py`

**Step 1:** Implement the script (complete):
```python
#!/usr/bin/env python3
"""Build per-language client-side search indexes from site/content.

Outputs site/static/search-index.<lang>.json. Run BEFORE `zola build`.
Each record: {title, url, section, tags, categories, date, excerpt}.
"""
from __future__ import annotations
import json, re
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]          # site/
CONTENT = ROOT / "content"
STATIC = ROOT / "static"
SKIP = {"sitemap"}

MD_IMG = re.compile(r"!\[[^\]]*\]\([^)]*\)")
MD_CODE = re.compile(r"```.*?```", re.S)
MD_LINK = re.compile(r"\[([^\]]+)\]\([^)]*\)")
MD_HTML = re.compile(r"<[^>]+>")
WS = re.compile(r"\s+")

def strip_fm(text: str) -> str:
    if text.startswith("+++"):
        i = text.find("\n+++", 3)
        return text[i + 4:] if i != -1 else ""
    return text

def parse_fm(text: str) -> dict:
    fm = {}
    if not text.startswith("+++"):
        return fm
    i = text.find("\n+++", 3)
    if i == -1:
        return fm
    block = text[3:i]
    for m in re.finditer(r'^([A-Za-z_]+)\s*=\s*(.+)$', block, re.M):
        k, v = m.group(1), m.group(2).strip()
        if v.startswith('"') and v.endswith('"'):
            v = v[1:-1]
        fm[k] = v
    return fm

def plain(body: str) -> str:
    body = MD_IMG.sub("", body)
    body = MD_CODE.sub("", body)
    body = MD_LINK.sub(r"\1", body)
    body = MD_HTML.sub("", body)
    body = re.sub(r"[#>*_`~=]+", " ", body)
    return WS.sub(" ", body).strip()

def collect(lang_dir: Path, lang: str, out: list):
    md_files = (lang_dir / "blog").glob("*.md") if (lang_dir / "blog").is_dir() else []
    md_files = list(md_files)
    for p in lang_dir.glob("*.md"):          # top-level pages
        md_files.append(p)
    for p in md_files:
        slug = p.stem
        if slug in SKIP or slug == "_index":
            continue
        text = p.read_text(encoding="utf-8")
        fm = parse_fm(text)
        if fm.get("hidden") == "true":
            continue
        body = strip_fm(text)
        summary = fm.get("description") or fm.get("summary") or ""
        excerpt = (summary + " " + plain(body))[:300].strip()
        url = f"/{lang}/" if lang != "en" else ""  # prefix for non-en
        if p.parent.name == "blog":
            url += f"blog/{slug}/"
        else:
            url += f"{slug}/"
        out.append({
            "title": fm.get("title", slug),
            "url": url,
            "section": "blog" if p.parent.name == "blog" else "page",
            "tags": fm.get("tags", ""),
            "categories": fm.get("categories", ""),
            "date": fm.get("date", ""),
            "excerpt": excerpt,
        })

def main():
    STATIC.mkdir(exist_ok=True)
    # EN (root content) + each translated dir
    langs = ["en"]
    for d in CONTENT.iterdir():
        if d.is_dir() and not d.name.startswith("_") and d.name not in ("blog", "static"):
            # only treat as lang dir if it has sub-content and isn't 'blog'
            if any(d.glob("*.md")) or (d / "blog").is_dir():
                langs.append(d.name)
    for lang in langs:
        out = []
        base = CONTENT if lang == "en" else CONTENT / lang
        if not base.exists():
            continue
        collect(base, lang, out)
        path = STATIC / f"search-index.{lang}.json"
        path.write_text(json.dumps(out, ensure_ascii=False), encoding="utf-8")
        print(f"wrote {path} ({len(out)} records)")

if __name__ == "__main__":
    main()
```

**Step 2:** Run it:

## Task 6: Search JS engine

**Objective:** Load index, run fuzzy search, render + keyboard-navigate results.

**Files:**
- Create: `site/static/js/search.js`

**Step 1:** Implement (complete):
```javascript
(function () {
  const TRIGGER = document.getElementById('site-search-trigger');
  const MODAL = document.getElementById('search-modal');
  const INPUT = document.getElementById('search-input');
  const RESULTS = document.getElementById('search-results');
  const EMPTY = document.getElementById('search-empty');
  if (!TRIGGER || !MODAL) return;

  const lang = document.documentElement.lang || 'en';
  const url = `/search-index.${lang}.json`;
  let fuse = null;

  function loadIndex() {
    return fetch(url).then(r => r.ok ? r.json() : fetch('/search-index.en.json').then(r => r.json()));
  }
  loadIndex().then(data => {
    fuse = new Fuse(data, {
      includeScore: true, threshold: 0.4, ignoreLocation: true,
      keys: [
        { name: 'title', weight: 0.4 },
        { name: 'tags', weight: 0.3 },
        { name: 'categories', weight: 0.3 },
        { name: 'excerpt', weight: 0.2 },
        { name: 'url', weight: 0.1 },
      ],
    });
  });

  let active = -1;
  function render(q) {
    RESULTS.innerHTML = '';
    if (!q || !fuse) { EMPTY.hidden = true; return; }
    const hits = fuse.search(q).slice(0, 12);
    if (!hits.length) { EMPTY.hidden = false; return; }
    EMPTY.hidden = true;
    hits.forEach((h, i) => {
      const li = document.createElement('li');
      if (i === active) li.className = 'active';
      li.innerHTML = `<a href="${h.item.url}">
        <div class="r-section">${h.item.section}</div>
        <div class="r-title">${h.item.title}</div>
        <div class="r-excerpt">${h.item.excerpt.slice(0, 140)}</div></a>`;
      RESULTS.appendChild(li);
    });
  }
  function open() { MODAL.classList.add('open'); INPUT.focus(); INPUT.value = ''; render(''); }
  function close() { MODAL.classList.remove('open'); active = -1; }

  TRIGGER.addEventListener('click', open);
  MODAL.addEventListener('click', e => { if (e.target === MODAL) close(); });
  INPUT.addEventListener('input', e => { active = -1; render(e.target.value); });
  document.addEventListener('keydown', e => {
    if ((e.metaKey || e.ctrlKey) && e.key.toLowerCase() === 'k') { e.preventDefault(); open(); }
    if (e.key === 'Escape' && MODAL.classList.contains('open')) close();
    if (!MODAL.classList.contains('open')) return;
    const items = RESULTS.querySelectorAll('li');
    if (e.key === 'ArrowDown') { active = Math.min(active + 1, items.length - 1); render(INPUT.value); }
    if (e.key === 'ArrowUp') { active = Math.max(active - 1, 0); render(INPUT.value); }
    if (e.key === 'Enter' && active >= 0 && items[active]) items[active].querySelector('a').click();
  });
})();
```

## Risks / Tradeoffs

- **Index size:** EN blog + pages is small (<50 KB). If marketing copy grows, re-evaluate; Fuse handles tens of thousands of records fine.
- **Translations:** Non-EN indexes only contain translated pages (mostly legal/sitemap). Blog is EN-only; searching in `/es/blog/` falls back to EN index — acceptable v1 behavior.
- **Freshness:** Index rebuilt every deploy; no runtime cost. If content changes without rebuild, search is stale until next deploy (same as the static site itself).
- **No server-side search:** Chosen for zero backend/edge simplicity. If needed later, a Worker route `/api/search` could proxy to a hosted index — out of scope for v1.
