# TrustBench marks

The Divinci robot already carries a heart. TrustBench is what happens when that
heart has to prove something — so the family is **one robot with a swappable
crest**, never a different robot.

| file | crest | used for |
|---|---|---|
| `trustbench-mark.svg` | heart + check | TrustBench itself |
| `trustbench-mark-redteam.svg` | heart drawn as a shield | Red Team Core |
| `trustbench-mark-extraction.svg` | shield + keyhole | System-Prompt Extraction |
| `trustbench-mark-grounding.svg` | heart + passage bars | RAG Grounding |
| `trustbench-mark-retrieval.svg` | heart + lens | the two Retrieval QA boards |
| `trustbench-mark-erasure.svg` | heart + struck seal | Annex IV corpus integrity |

Generated by `_build-marks.py` from a single robot body — edit the script, not
the SVGs, or the family drifts apart one file at a time.

## ⚠️ Inline them

Every mark is `fill="currentColor"`, which inherits **only when the SVG is part
of the host document**. Through `<img>` or `background-image` it is its own
document, inherits nothing, and falls back to the `svg:root` default — so a
mark placed in an `<img>` on a dark surface renders dark-on-dark. That is how
these first rendered on the contact sheet's midnight strip.

Inline the file and set `color` on the container:

```html
<span class="tb-mark" style="color: var(--text-primary)"><!-- paste svg --></span>
```

A `prefers-color-scheme` branch was tried and removed: it made the mark follow
the viewer's OS rather than the surface it sits on, which vanished inside an
`<img>` on a cream page. Predictable beats clever.

## Checking a change

`_contact-sheet.html` renders all six inlined at 96/48/24px on cream and on
midnight ink. Serve the directory and open it:

```bash
python3 -m http.server 8899   # then http://127.0.0.1:8899/_contact-sheet.html
```

The 24px column is the one that matters — the first pass had crests so large
they ate the heart silhouette, which only showed up at small sizes.
