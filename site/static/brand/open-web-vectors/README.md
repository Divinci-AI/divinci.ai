# Open Web Vector Initiative — brand assets

Generated by `scripts/build-owv-brand.py` (SVG) and `scripts/render-owv-brand.mjs`
(PNG). Edit the geometry in the script, not the files.

**The mark** is a globe seen from the pole — the outer ring is the equator, six
meridians, one latitude ring — with an indexed site at every crossing and at the
pole. The six crossings are the six seed-of-life centres the `/open-web-vectors/`
hero orbit is drawn from, so the icon is the hero's geometry at 22px.

| File | Use |
|---|---|
| `owv-mark.svg` | Monochrome, `currentColor`. Inline UI, nav thumbs. |
| `owv-mark-dark.svg` / `-light.svg` | Two-tone (indigo linework, gold nodes) for dark / light surfaces. |
| `owv-logo-dark.svg` / `-light.svg` | Horizontal lockup, text as outlines (Fraunces 600 / Source Sans 3 600). |
| `owv-logo-stacked-*.svg` | Stacked lockup for square placements. |
| `owv-banner.svg` / `.png` | The dark lockup on its own navy plate — for READMEs and Hugging Face cards, where the page theme is unknown. |
| `*.png` | 1200px / 512px renders of the above for places that cannot embed SVG. |

Also emitted: `templates/partials/owv-mark.html`, the inline mark with class
hooks (`.owv-mark`, `.owv-mark-node`) so a page can colour the nodes separately.

Colours: dark surfaces `#8d8de3` lines / `#d9c49a` nodes; light surfaces
`#4a45b8` / `#a8865a`. Clear space: half the mark's width on every side.
