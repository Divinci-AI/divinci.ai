# Divinci Local Inference — 개인정보 처리방침

**최종 업데이트:** 2026년 6월

본 방침은 **Divinci Local Inference** Chrome 확장 프로그램에 한해 적용됩니다.
Divinci AI의 웹사이트, 앱 및 서비스 전반에 대해서는 당사의 메인
[개인정보 처리방침](/ko/privacy-policy/)을 참조하십시오.

Divinci Local Inference는 오픈 웨이트 AI 모델(Google의 Gemma 4)을 귀하의
브라우저에서 귀하의 GPU를 통해 로컬로 실행하며, 로그인을 선택한 경우
해당 로컬 어시스턴트를 귀하의 Divinci 계정에 연결하여 선택적인 클라우드
지원 기능을 제공합니다. 본 방침은 기기에 남는 항목과 특정 상황에서
Divinci로 전송되는 항목을 정확히 설명합니다.

**요약:** 기본적으로 이 확장 프로그램은 로컬 전용입니다 — 온디바이스
모델과의 채팅은 귀하의 컴퓨터를 벗어나지 않습니다. 일부 선택적이고
명확하게 통제 가능한 기능(로그인, 페이지 인식 답변, 계정 모드 채팅)은
Divinci로 데이터를 전송합니다. 이러한 기능은 아래에서 설명합니다. 당사는
귀하의 데이터를 판매하거나, 광고를 표시하거나, 이를 이용해 웹에서 귀하를
추적하지 않습니다.

## 1. 기기에 남는 항목(기본값)

- **로컬 Gemma 모델과의 채팅.** 프롬프트와 응답은 귀하의 GPU에서 연산되며,
  확장 프로그램에 의해 기록, 저장 또는 전송되지 않습니다. (예외: §3 및
  §4의 두 가지 선택적 기능.)
- **모델 파일**은 최초 다운로드 후 브라우저에 캐시됩니다.
- **귀하의 설정**(선택한 모델, 추론 기본값, 개인정보 보호 토글)은
  브라우저에 로컬로 저장됩니다.

**로그인하지 않은 경우**, 확장 프로그램은 Divinci로 브라우징 정보를
**전혀** 전송하지 않습니다.

## 2. Divinci 로그인(선택 사항)

**로그인 / 회원가입**을 클릭하면, 확장 프로그램은 Divinci의 신원 제공업체
(Auth0)를 통해 표준 OAuth 로그인을 완료합니다. 성공하면 당사는 **귀하의
기기에** 액세스 토큰과 귀하의 기본 프로필(이메일, 이름, 아바타 URL)을
수신하여 저장하며, 이를 통해 확장 프로그램이 로그인 상태를 표시하고
귀하를 대신하여 인증된 요청을 수행할 수 있습니다. 액세스 토큰은 확장
프로그램의 백그라운드 서비스 워커를 벗어나지 않습니다. 언제든지 툴바
팝업에서 로그아웃할 수 있으며, 로그아웃 시 저장된 토큰이 삭제됩니다.

## 3. 웹 브라우징 활동(로그인 상태이며 **동시에** 패널이 열려 있는 경우에만)

귀하가 보고 있는 페이지가 Divinci의 공유 공개 웹 지식 색인에 포함되어
있는지 알려주고 답변의 근거로 삼기 위해, 확장 프로그램은 — **귀하가
로그인한 상태이며 Divinci 사이드 패널을 페이지에서 열어둔 경우에만** —
다음을 Divinci의 API로 전송합니다:

- **페이지 주소**로, 출처(origin)와 경로(path)로만 축약됩니다. 쿼리
  문자열과 프래그먼트(`?` 및 `#` 이후 부분으로, 검색어, 토큰 또는 개인
  식별 정보를 포함할 수 있음)는 **전송 전에 제거됩니다**.
- **페이지의 표시된 텍스트에 대한 단방향 지문(해시)**으로, 당사의 색인이
  최신 상태인지 확인하는 데 사용됩니다. **페이지의 실제 콘텐츠는
  전송되지 않으며** — 이 해시와 축약된 주소만 전송됩니다.

중요한 제한 사항:

- 이는 페이지에서 **사이드 패널이 열려 있는 동안에만** 발생합니다.
  패널이 닫혀 있으면, 확장 프로그램은 귀하가 방문하는 페이지에 대해
  아무것도 전송하지 않습니다.
- **민감한 사이트는 전적으로 건너뜁니다** — 확장 프로그램은
  로그인/계정 페이지, 은행 및 금융 사이트, 웹메일, 의료 포털, 로컬/사설
  주소, 또는 비표준 포트에 대해서는 아무것도 전송하지 않습니다.
- 이는 공개 웹 색인을 조회하고 최신화하는 데 사용되며, **귀하의 프로필을
  구축하거나 광고를 타겟팅하는 데 사용되지 않습니다.**

공유 색인 자체는 Divinci가 자사 서버에서 **공개적으로 접근 가능한** 웹
페이지를 크롤링하여 구축하며, 이 확장 프로그램은 색인 구축을 위해
페이지 콘텐츠를 업로드하지 않습니다.

## 4. 페이지 인식 답변 및 계정 모드 채팅(선택 사항)

- **페이지 인식 답변(근거 부여, grounding).** 페이지가 색인에 포함되어
  있고 귀하가 사이드 패널에서 메시지를 보내면, 확장 프로그램은 **귀하의
  메시지와 축약된 페이지 주소**를 Divinci로 전송하여 관련 컨텍스트를
  검색하며, 이는 로컬 모델에 제공됩니다. 따라서 이 경우 귀하의 채팅
  메시지는 기기를 벗어납니다. 이 기능은 끌 수 있습니다 — §5를 참조하십시오.
- **계정 모드 채팅.** 채팅에서 *"내 Divinci 계정 사용"*을 활성화하면,
  귀하의 대화는 (서버 호스팅 모델 및 도구를 실행하기 위해) Divinci의
  서버로 전송되며, chat.divinci.app에서 채팅하는 것과 동일하게 귀하의
  계정에 트랜스크립트로 저장됩니다. 이 기능을 끄면 채팅이 완전히
  로컬로 유지됩니다.

## 5. 귀하의 개인정보 보호 설정

팝업의 **고급 설정 → 개인정보 보호**에서:

- **Divinci 페이지 컨텍스트 검색** — 끄면, 확장 프로그램은 페이지 인식
  답변을 위한 귀하의 메시지를 전송하지 않습니다(귀하의 채팅 질의는
  기기에 남습니다). 기본값: 켜짐.
- **Divinci가 내 계정 채팅을 사용하도록 허용** — 끄면, 확장 프로그램은
  Divinci에게 귀하의 계정 모드 채팅을 서비스 개선에 사용하지 말 것을
  요청합니다. 기본값: 켜짐. (이는 요청과 함께 옵트아웃 신호를
  전송하는 방식이며, 실제 처리는 Divinci의 서버에서 시행됩니다.)

또한 언제든지 **로그아웃 상태(완전 로컬)를 유지**하거나 **로그아웃**하여
§2~§4의 모든 기능을 중단할 수 있습니다.

## 6. 데이터가 전송되는 위치

- **huggingface.co**(및 CDN `cas-bridge.xethub.hf.co`) — 모델 파일을
  다운로드하기 위함이며, [Hugging Face 개인정보 처리방침](https://huggingface.co/privacy)의
  적용을 받습니다.
- **Divinci의 신원 제공업체**(Auth0) — 로그인 시에만.
- **Divinci의 API**(`api.divinci.app`) — §3 및 §4의 로그인 기반 기능을
  위함.

## 7. 당사가 **하지 않는** 것

- 당사는 귀하의 데이터를 판매하거나 대여하지 **않습니다.**
- 당사는 광고를 표시하거나 귀하의 데이터를 광고 또는 사이트 간 추적에
  사용하지 **않습니다.**
- 당사는 귀하가 방문하는 페이지의 **콘텐츠**를 전송하지 **않습니다**
  (§3에 따라 축약된 주소와 단방향 해시만 전송됩니다).
- 귀하가 로그아웃 상태이거나 사이드 패널이 닫혀 있을 때는, 귀하의
  브라우징에 관한 어떠한 것도 전송하지 **않습니다.**

## 8. 권한

- **offscreen** — WebGPU 모델을 실행합니다.
- **storage** — 설정과 캐시된 모델 환경설정을 로컬에 저장합니다.
- **identity** — 귀하의 Divinci 계정에 대한 OAuth 로그인을 완료합니다(§2).
- **호스트 권한**(`api.divinci.app` 및 Auth0 로그인 출처) — §2~§4의
  인증된 요청을 수행합니다.
- **모든 사이트의 콘텐츠 스크립트** — 사이드 패널을 그리고, 패널이 열려
  있고 로그인한 경우에만 §3의 페이지 색인 확인을 실행합니다. 스크립트는
  해시를 계산하기 위해 페이지 제목, 주소, 표시된 텍스트를 **로컬에서**
  읽습니다; 페이지 콘텐츠를 전송하지 않습니다.
- **externally_connectable**(Divinci AI 도메인 한정) — chat.divinci.app이
  `chrome.runtime` 포트를 통해 로컬 모델을 사용할 수 있게 합니다.

## 9. 오픈 소스

이 확장 프로그램은 Apache-2.0 라이선스를 따르며, 소스 코드는
[github.com/Divinci-AI/gemma-gem](https://github.com/Divinci-AI/gemma-gem)에서
확인할 수 있습니다.

## 10. 본 방침의 변경

확장 프로그램이 데이터를 처리하는 방식을 변경하는 경우, 당사는 본
방침을 업데이트하고 확장 프로그램 버전을 갱신합니다(`chrome://extensions`
카드에 표시됨).
